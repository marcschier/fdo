# Changelog

## 0.1.0-preview

- Add paired FDO 2.0 Device Initialize, voucher transfer, and direct and
  delegated Rendezvous exchanges.
- Add protected paired enrollment with credential reuse and replacement, and
  selected `fdo.csr` operations. See [qualification and support](docs/FdoQualification.md)
  for protocol and platform limits.
- License the project under MIT and include the license in the NuGet package.
- Add runnable Device initialization and voucher transfer samples for
  in-process and HTTP loopback transports.
